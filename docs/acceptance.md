## 同一插件覆盖安装

用户确认同一插件安装后覆盖原安装，市场无需展示多个版本入口。市场以 `package.json.name` 为插件唯一标识，每个插件只返回 npm SemVer 最大的发布版本；客户端将它与该用户的当前安装按同一标识关联，只显示一张卡片。已安装版本可以打开，新版本在同一卡片更新；成功后替换当前版本，失败保留原入口。

真实 PostgreSQL 下市场测试 13/13 通过。新增回归先复现同一插件返回三条版本，再验证 `0.1.10` 高于 `0.1.9`，且安装更新后只有一条记录、安装记录 ID 保持不变。当前内置浏览器的 5 项定向检查通过：Grove 从两张卡变为一张，测试插件从 `0.1.9` 覆盖至 `0.1.10`，刷新后仍为新版本；`0.1.11` 真实容器创建失败后，旧版本的打开入口与 iframe 地址保持可用。原生数据库记录也确认成功与失败后均只有同一条安装记录。

类型检查、客户端及服务端构建通过。测试专用插件、安装记录、发布目录、空业务库、角色及网络已清理；该次检查结束时 Grove 和官方笔记仍保留。证据在独立测试目录 `workdashboard-testing/isola-overwrite-20261011`。本次未重复未修改的后端恢复与完整三引擎测试。
